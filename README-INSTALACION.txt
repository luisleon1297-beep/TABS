CUERDA PARA IPHONE · PWA

Esta versión usa el código de Cuerda Windows 2.0 y adapta el almacenamiento a Safari.

PUBLICACIÓN GRATIS CON GITHUB PAGES:
1. Crea un repositorio público llamado Cuerda-iPhone en GitHub.
2. Sube LOS ARCHIVOS Y CARPETAS que están dentro de este ZIP a la raíz del repositorio (index.html debe quedar en la raíz).
3. Ve a Settings > Pages > Build and deployment > Deploy from a branch.
4. Selecciona main y / (root), guarda y espera a que aparezca tu URL HTTPS.
5. Abre esa URL en Safari en el iPhone.
6. Toca Compartir > Añadir a pantalla de inicio > Añadir.

USO:
- Busca canciones con Internet (catálogo iTunes).
- Para videos pega una URL de YouTube; algunas reproducciones embebidas pueden estar restringidas.
- Para tablaturas usa los enlaces de búsqueda de Cifra Club o GuitarTuna, copia y pega el contenido que tengas derecho a usar.
- Edita y guarda acordes; historial y favoritos se almacenan en el dispositivo.
- Los datos guardados no se sincronizan entre Windows e iPhone.
- La interfaz y tablaturas guardadas pueden abrirse sin conexión tras la primera carga; búsqueda y videos requieren Internet.
- No abras index.html directamente como file:// para instalar: se requiere HTTPS o localhost.
- No borres los datos de Safari para ese sitio si quieres conservar historial y tablaturas.

NOTA: Es una reconstrucción web, no una app publicada en App Store. No incluye importación automática de tablaturas externas.
